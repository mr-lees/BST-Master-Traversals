Eduqas Dynamic Memory Model

2D Array / Parallel Arrays Pointer Representation

In Eduqas A-Level Computer Science, trees are frequently represented in memory using parallel 1D arrays or a 2D array. Null pointers are designated using -1 (or NULL).

Memory Table: [Index, Data, LeftPointer, RightPointer] Root Index: 0
Array Index Data Value Left Pointer Right Pointer Status

How Pointers Work in Array Form

Each array entry contains the node value alongside integer indices pointing to left and right children. A value of -1 indicates no child node (NULL pointer).

Eduqas Pen-and-Paper Exam Technique

The Outline / Boundary / Flag Method

Eduqas examiners recommend drawing an unbroken line around the outside of the tree structure (starting from the left of the root) and adding dots/flags to nodes based on traversal type.

NLR (Pre-Order) Left Dot

Place a flag/dot on the LEFT side of every node. As you trace around the border, record the node value when your pen touches the left dot.

LNR (In-Order) Bottom Dot

Place a flag/dot on the BOTTOM of every node. Record the node value as your boundary pen passes under the bottom of each node.

LRN (Post-Order) Right Dot

Place a flag/dot on the RIGHT side of every node. Record the node value as your pen touches the right dot while looping back upwards.

Eduqas Exam Tip: In Component 1 questions asking for tree traversals, always sketch the outline boundary method in pencil on the tree diagram provided on your exam paper to avoid missing nodes or misordering sequences!

NLR / Pre-Order

Pre-Order Traversal

Visits Root node first, then recursively visits Left subtree and Right subtree.

  • Tree Cloning / Duplication: Preserves original BST structure upon re-insertion.
  • Prefix Evaluation: Evaluates operator expression trees (Polish Notation).
  • Directory Traversal: Traverses directory hierarchies top-down.
LNR / In-Order

In-Order Traversal

Recursively traverses Left subtree, visits Root node, then recursively traverses Right subtree.

  • Ascending Order Output: Retrieves BST key values in ascending sorted sequence.
  • Infix Notation: Outputs standard arithmetic math expressions with operators between operands.
LRN / Post-Order

Post-Order Traversal

Recursively processes Left subtree, then Right subtree, and finally visits Root node.

  • Safe Memory Deallocation: Deletes child nodes prior to parent nodes (bottom-up deletion).
  • Reverse Polish Notation (RPN): Converts expression trees to postfix strings for stack calculators.
  • Directory Size Calculation: Aggregates subdirectory file sizes before root folder.

Eduqas Node Deletion Rules (3 Cases)

Case 1: Leaf Node (0 Children) Set parent pointer referencing target node to -1 (NULL).
Case 2: 1 Child Node Bypass target node by setting parent pointer directly to target node's single child.
Case 3: 2 Children Nodes Locate In-Order Successor (smallest value in right subtree), replace target value with successor value, then remove successor leaf.
